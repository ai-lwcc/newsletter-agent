# Audit Logs

The Audit Log system records important staff actions for accountability and troubleshooting.

## Tracked Actions

### Campaign Actions

- AI Campaign Created
- AI Draft Queued
- AI Groups Accepted
- Dry Run Created
- Test Email Sent
- Real Send Requested
- Failed Emails Retried

## Audit Log Information

Each entry records:

- Time
- User
- Campaign
- Action
- Additional Details

## Filtering

Audit logs can be filtered by:

- Action
- Campaign

## Pagination

Results are paginated to improve performance.

## Example Workflow

AI Campaign Created
→ AI Draft Queued
→ AI Groups Accepted
→ Dry Run Created
→ Test Email Sent
→ Real Send Requested

This provides a complete history of campaign activity.
