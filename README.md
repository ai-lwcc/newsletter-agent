# Newsletter Agent

A Django-based app for managing contacts, creating newsletter campaigns, previewing emails, sending PDFs by email/WhatsApp, and scheduling recurring sends.

## Current Features

- Contact and group database
- Excel contact import
- Google Sheets import foundation
- Campaign creation
- PDF attachments
- Campaign preview page
- Recipient preview page
- Dry-run delivery logs
- Safe real-send confirmation flow
- Delivery log tracking
- Retry failed emails
- Brevo SMTP configuration documentation
